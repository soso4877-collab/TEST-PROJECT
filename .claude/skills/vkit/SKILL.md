# /vkit — 다층 검증 키트 스캐폴딩

규격 = `docs/21-verification-kit.md`. 정본 = `handoff/kit/`. 배포 = 복사-적응 + 출처 스탬프
벤더링(pip 패키지·생성기 아님 — 하드게이트 결정론·무의존 불변). **"복사했다"가 아니라 "안전장치
4대 통과"로 이식이 완료된다** — 이 스킬은 그 4대를 배선하는 골격을 찍는 것이 핵심이다.

인자 `$ARGUMENTS` = 대상 프로젝트 경로(+ 선택: 채택할 층 L0~L4).

## 절차
1. **경계표 대조**: `docs/21`의 "측정된 이식 경계표"를 읽어 각 아티팩트의 이식 등급(그대로/적응/
   재작성)을 대상 도메인에 매핑한다. "그대로 복사"를 맹신하지 마라 — sajugen 리터럴을 색출한다.
2. **매니페스트 스탬프**: `handoff/kit/manifest.template.json`을 대상 `handoff/kit/manifest.json`으로
   복사하고 `upstream_sha`(= `git rev-parse HEAD`)·`copied_at`·`adopted_by`를 채운다.
3. **정본 복사 + 적응**: 경계표 등급대로 복사한다. 적응/재작성 대상은 도메인 특화가 필요함을
   대상 프로젝트에 TODO 로 남긴다(빈 스텁을 "게이트 있음"으로 위장하지 마라 = 껍데기 no-op 금지).
4. **안전장치 4대 골격 생성**(이게 핵심 — 미배선 시 팬텀 메타 재현):
   - **no-op 자가검증**: 각 이식 게이트에 "결함 주입→차단" 양방 테스트 스텁 + CI 배선 확인 항목.
   - **PII 형상 재정의**: 도메인 PII(예: crypto=지갑·키·시크릿) 마스킹 룰 + 그 PII 주입이 실제
     차단됨을 확인하는 테스트 스텁. sajugen 생년월일 룰을 그대로 두지 마라(탐지 no-op).
   - **이질성 검증**: L2 생성 모델 ≠ 비평/judge 모델을 대상 config 로 확인하는 테스트 스텁.
   - **도메인 리터럴 치환**: deadparam_scan 의 경로·GATE floor 매직넘버 등을 대상 트리로 치환.
5. **채택 체크리스트**: `docs/21` 4대를 대상 `handoff/kit/` 에 체크리스트로 찍고, manifest 의
   `safeguards_verified` 를 전부 false 로 초기화(사람이 통과시켜야 true).

## 규율
- **껍데기 게이트 금지(fail-closed)**: 배선 없는 스텁을 "게이트 있음"으로 표기하지 마라. 값이 없으면
  통과가 아니라 명시적 TODO/실패로 남긴다(no-op 대량 생산이 이 키트가 막으려는 바로 그 결함).
- **하드게이트 결정론·무의존 유지**: 대상에 외부 패키지 의존을 심지 마라(stdlib 우선).
- **PII 0**: 스캐폴딩은 대상 도메인 PII 형상을 재정의하지 않으면 미완료로 보고한다.
- 이 저장소(sajugen) 자체는 스캐폴딩 대상이 아니다(이미 정본). 대상은 항상 별도 프로젝트.
- 전역화(~/.claude/skills/vkit/ 승격 = 크로스 프로젝트 가용)는 시스템 변경이라 운영자가 결정한다.
