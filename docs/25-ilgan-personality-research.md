### 1-1. 코드 렌더 계약 (승인 — 이 표가 `myeongni_persona.py` 오라클의 독립 근거)
§1 전통 상징은 복수 대안(동량·등불·성벽·화원 등)을 담고 일부는 style 가드에 걸린다(등불=시적 수사).

(코드가 이 축을 빠뜨리면 회귀 실패). 문형·조사·연결어의 표현 자유는 필수 축 보존 하에 승인된다.

## 2. 신강/신약 modifier (발현 방향만 — 성격을 새로 만들지 않음)
- **신강**: 자기주도·추진·독립·책임 강화 / 과하면 고집·독선·밀어붙임 → 일간의 능동·발산 쪽을 키워 읽음.
- **신약**: 수용·협조·민감·신중 / 과하면 결단 약·의지처 필요 → 수용·조율 쪽을 키워 읽음. **약함이 아니라
  민감·수용**으로 재서술.
- 원칙 = 억부("강한 건 누르고 약한 건 돕는다"). 신강=좋음/신약=나쁨 아님. 판정 산법에 유파차가 있어
  경계 사주는 단정 보류.

## 3. 십성 5축 성격 + 과다 그늘 (기질=B / 과다 그늘=C)
- **비겁**: 주체성·독립·경쟁 돌파 / 과다→자기중심·마찰
- **식상**: 표현·재능·생산 / 과다→과잉 표출·구설·마무리 약함
- **재성**: 현실 감각·재물 운용 / 과다→물욕 과열·이해타산
- **관성**: 책임·절제(정관)·결단·위기대응(편관) / 과다→자기 압박·경직·조급
- **인성**: 배움·수용(정인)·독창·통찰(편인) / 과다→실행 약함·의존·고립
- 정/편: 편=민감·즉발·순발력, 정=정돈·안정·느린 반응. **과다 그늘 문구는 C(확정불가)** — 조심스럽게.

## 4. 없는/약한 오행 성정 (결핍↔갈망 양가 — 단일 결핍 서사 금지)
- 목 결: 감정 표현·유연 부족(냉정하게 비침) — 유연을 의식적으로 기를 여지.
- 화 결: 발산·즉흥 기쁨·존재감 결핍 — **오히려 인정 욕구가 강해지기도**.
- 토 결: 안정·인내·마무리 약(가벼워 보임) — 꾸준함을 습관으로 채울 여지.
- 금 결: 결단·절제·맺고끊음 약 — 기준을 세우면 보완.
- 수 결: 지혜·유연·수용 결핍 — **오히려 공부·탐구에 집착하기도**.
- 유파차: "결핍" vs "없어서 강하게 추구" vs "지장간·대운 보충 시 결핍 아님" 공존 → **양가 병기**, "약한(미약)"과
  "없는(0개)" 구분.

## 5. 신뢰도 등급
- **A**: 음양·오행·자연물 상징(전통 물상 기본), 적천수 `甲=參天` 앵커.
- **B**: 10천간 성격 형용사·그늘, 십성 5축 기질, 신강/신약 방향.
- **C(확정불가·조심)**: 적천수 9간 구절 원전 대조 미완, 물상론 비판 원전 대조 미완, 십성 과다 그늘 문구.

## 6. 유파차·확정불가 (정직성 우선)
- 물상론 vs 고전 자평은 "배격"이 아니라 **방법·강조 차이**. 적천수 십간론 자체가 물상 이미지를 포함
  (`甲木參天 脫胎要火`). "자평진전·적천수천미·명리약언이 물상론을 근거없다 비판"이라는 정리는 현대 해설에
  반복되나 **3원전 원문 직접 대조 미완 → C, 강한 비판 단정 채택 보류**.
- 상용·AI 명리 사이트는 학술 권위가 아니고 동일 전통 파생 → "일치=독립검증" 아님. 성격 어휘 신뢰 상한 B.

## 8. 코드 배선 지침 (로드맵 1e)
- 사주 간지·십성·신강·오행분포는 엔진 사실 슬롯(계산). 이 문서는 성격 '의미'만 — content 층.
- 신규 canon 모듈(`content/myeongni_persona.py`): `GAN_PERSONA`(10간 상징·기질·그늘)·`SINGANG_MODIFIER`
  (신강/신약/중화 발현 방향)·`ELEM_LACK`(오행 결핍↔갈망 양가)를 우선 배선. **정본 밖 성격어 생성 금지**
  (factcheck 비검사 영역이라 정본 이탈 = 할루시네이션 → 이 문서를 단일 소스로).
- §3 십성 성격 심화(`SS_PERSONA`)는 **후속**(현재 `_SS_MEAN`/`_ss_list` 유지) — 1e는 일간·신강·없는오행
  (최대 결손)과 다단 인과를 우선한다. §3은 문서 canon으로 보존하되 코드 배선은 다음 라운드.
- 소비처: `rules.py`의 `ilgan`·`strength`·`character` 골격에 다단 인과("일간 성격 → 신강이 그 방향으로 →
  십성/신살이 더하는 색 → 반복 행동")로 배선. `_LAYER_WEAVE`(llm_sections)를 명리↔자미 사실특정 확증으로.
- **비단정 필수(B급)**: "~한 경향", "유파에 따라 ~로 봅니다" 톤. 단정("반드시 ~다") 금지. 문형 `_pick` 다양화.
- 양방 테스트: 정상 성격 서술 통과 + 예측/길흉/성별 단정 주입 차단 + 데이터 순정 + 10간 전수 커버.
