## 0. 결론 먼저

1. **고전은 起運 거리를 "출생 時辰 ↔ 절입 時辰" 사이를 日·時 단위로 세라고 명시한다**(三命通會). 여기서 時 는
   시주(時柱)를 정하는 바로 그 출생 시진이다 — 별도의 시간 체계가 아니다. 시각의 물리 기준(지방시·진태양시)은
   고전에 언급이 없다(당시엔 지방 진태양시 외 다른 시계가 없었으므로 구분 자체가 불필요했다).
2. **따라서 "起運 시진 버킷 = 시주와 같은 국지축(진태양시+자시 정책)"** 이 고전 문언에 가장 충실한 해석이다.
   현행(CST 프레임 시진)은 고전·한국 관행 어느 쪽에도 근거가 없는 **구현 부산물**이다(`docs/26` §3-2 와 일치).
3. 반사실 프로브(25,440건 층화 격자): 현행(A) ↔ 진태양시 버킷(C) 의 `start_year` 불일치 **0.53%**, 대운수 불일치
   **0.59%**. 현행 ↔ 시민 KST 버킷(B) 은 **1.53%**. 즉 A→C 로 바꾸면 영향 범위는 B 안의 약 1/3 이다.
4. **流派2(분 단위 정밀)는 프레임 불변이 아니다** — 거리 끝점이 CST 절기표라 시민 KST 투입 시 거리가 60분 틀어져
   1.53% 가 바뀐다. 이는 "거리 = 절대축(현행 옳음)" 을 수치로 재확인한 것이고, 시진 버킷만이 미결 축이다.
5. 한국 실무는 둘로 갈린다: (가) **일수÷3 + 나머지 처리**(1 버림·2 올림 / 또는 반올림 — 백민 명리학개론 계열,
   위키·강의·brunch), (나) **시·분까지 정밀 계산**(sajumania: "시간과 분까지 계산", DE431 입기시각). 진태양시를
   起運에 명시 적용한다는 한국 자료는 **찾지 못했다**(시주에는 진태양시 적용이 통설). 대운수 나이는 **만 나이**
   (三命通會 "實經歷過" 논증, sajustudy) — 현행 코드 주석과 일치.

## 1. 1차 자료 (원문 인용 — 2026-08-22 확인)

### 1-1. 三命通會 卷二 「論大運」(明 萬民英) — 핵심 1차 자료
- 折除 원리: 「古人以大運則一辰十歲，折除以三日為年者何？蓋一月之終，晦朔周而有三十日，一日之終，晝夜周而有十二時；
  總十年之運氣，凡三日，有三十六時，乃見三百六十日為一歲之數。」
- **방향과 단위**: 「陽男陰女，大運以生日後未來節氣**日時**為數，順而行之；陰男陽女，大運以生日前過去節氣**日時**為數，
  逆而行之。」
- **예시(時辰 단위 계산의 실증)**: 「假如甲子陽男十二月二十四日**巳時**生，是月也，二十九日**申時**立春，陽男數以未來之日，
  自二十四日巳時至二十五日巳時，方是一日之實數，至二十九日申時正得**五日三時**之節氣」
- 만 나이 근거: 「實經歷過二十有一之日，月運方移宮」(경과 기간으로 서술).
- 출처: 古文島 전재 https://m.guwendao.net/guwen/bookv_8dc528e1b59d.aspx · udn 전재 https://blog.udn.com/DejaVu/3146071
  · 四庫全書本 維基文庫 https://zh.wikisource.org/zh-hant/三命通會_(四庫全書本)/全覽
- **해석**: 거리 = (출생일·출생 時辰) → (절입일·절입 時辰), 日 과 時辰 두 단위. 時辰 은 출생 시진 그 자체(시주와 동일).
  1時辰 = 10日 환산은 여기서 파생(3日=1歲=360日 ⇒ 1日=120日=4개월 ⇒ 1時辰=10日).

해석:
- A↔B 1.53% 는 `docs/26` A-1 의 1.42% 와 같은 자릿수(격자 동일·DST 처리만 다름: 이번엔 `ct.utc+8h` 로 1987-88 서머타임 반영).
- **A↔C 0.53%**: 현행을 고전 해석(국지축 시진)으로 바꿨을 때 실제로 달라지는 고객 비율. 진태양시는 서울 기준 −32분 ± 균시차라
  시진 경계를 넘는 폭이 CST(−60분)의 절반 정도 → 불일치도 약 1/3.
- **流派2 는 프레임 불변이 아니다**(D 행): 절입 시각이 CST 절기표에 있으므로 시민 KST 투입은 거리를 60분 틀어 놓는다.
  60/4320 = 1.39% 이론치 ≈ 1.53% 실측. ⇒ 거리는 반드시 절대축(현행) — 이 부분은 유파 문제가 아니라 물리다.
- 流派1↔流派2(같은 프레임) 1.52%: 시진 버킷 이산화 자체가 대운수를 1.5% 에서 바꾼다. 한국 실무 (가)·(나) 의 차이가 이 크기다.
- 00시대 잔차(12~32건)는 (c) 달력 앵커 메커니즘 — 어느 축을 택해도 별도로 시민 KST 앵커로 고쳐야 한다.

  공개 자료로 확인되는 한국 관행은 (가) 일수÷3(시·분 무시) 와 (나) 시·분 정밀(sajumania) 뿐이며, 어느 쪽도 시진 버킷의 시제를 명시하지 않는다.

## 부록 A. `f1_axis_probe.py` (전문 — 저장소 밖 scratchpad 실행, 비커밋 규율)

```python
# -*- coding: utf-8 -*-
"""F-1 반사실 프로브: 起運 시진 버킷의 축을 한 번에 하나만 바꿔 기여도를 분리한다.
A=CST(현행)=ct.utc+8h / B=ct.civil_local / C=ct.true_solar, 각 流派1; D=流派2 를 A·B 프레임에.
실행: ./.venv/Scripts/python.exe -X utf8 f1_axis_probe.py  (repo root 를 sys.path 에 추가)
"""
import sys
from datetime import datetime, timedelta
sys.path.insert(0, r"C:\Users\pc\test-project")
from lunar_python import EightChar, Solar
from sajugen.input.time_correction import correct
H = 8

def yun_of(dt, is_male, sect):
    lunar = Solar.fromYmdHms(dt.year, dt.month, dt.day, dt.hour, dt.minute, 0).getLunar()
    yun = EightChar(lunar).getYun(1 if is_male else 0, sect)
    return yun.getStartYear(), [x.getStartYear() for x in yun.getDaYun()[1:9] if x.getGanZhi()]

pairs = [("A_cst","B_kst"),("A_cst","C_tst"),("B_kst","C_tst"),("D_cst2","D_kst2"),("A_cst","D_cst2"),("C_tst","D_cst2")]
cnt_q = {p:0 for p in pairs}; cnt_sy = {p:0 for p in pairs}; by_hour = {p:{} for p in pairs}; total = 0
for yy in range(1985, 1995):
    d = datetime(yy, 1, 1)
    while d.year == yy:
        for h in range(24):
            for male in (True, False):
                ct = correct(d.year, d.month, d.day, h, 30)
                cst = ct.utc + timedelta(hours=H)
                f = {"A_cst": yun_of(cst, male, 1), "B_kst": yun_of(ct.civil_local, male, 1),
                     "C_tst": yun_of(ct.true_solar, male, 1), "D_cst2": yun_of(cst, male, 2),
                     "D_kst2": yun_of(ct.civil_local, male, 2)}
                total += 1
                for p in pairs:
                    if f[p[0]][0] != f[p[1]][0]: cnt_q[p] += 1
                    if f[p[0]][1] != f[p[1]][1]:
                        cnt_sy[p] += 1; by_hour[p][h] = by_hour[p].get(h, 0) + 1
        d += timedelta(days=7)
print(f"표본 {total:,}건")
for p in pairs:
    print(f"[{p[0]} vs {p[1]}] 대운수 {cnt_q[p]} ({cnt_q[p]/total*100:.2f}%) / start_year {cnt_sy[p]} ({cnt_sy[p]/total*100:.2f}%)")
    odd = sum(v for k,v in by_hour[p].items() if k%2==1); even = sum(v for k,v in by_hour[p].items() if k%2==0 and k!=0)
    print(f"   홀수시 {odd} / 짝수시(0제외) {even} / 00시 {by_hour[p].get(0,0)}")
```

## 부록 D. 정정 — §2 프로브 C 는 "출생 끝점만" 옮긴 측정이었다 (2026-08-23, 구현 중 발견)

§2 의 C(진태양시)는 출생 시각만 진태양시 시계로 넣고 **절입 끝점은 lunar CST 시계에 그대로** 둔 측정이다(두 시계가 섞임).
패킷 §3-1 은 "출생·절입 둘 다 같은 국지 시계에서 日·時辰을 센다"(한 시계에서만 자리올림이 일관)로 설계했고, 그 정의의 변동률은
§2 의 0.53% 가 아니다. 折除를 직접 구현한 프로브3(같은 25,440 격자, 절입은 lunar 절기표):

| 비교 | 대운수 변동 |
|---|---:|
| A 현행 vs C (출생만 진태양시, 절입 CST, 23=亥) | 143 (0.56%) — §2 재현 |
| **A 현행 vs C′ (둘 다 진태양시 시계, 23=子)** | **905 (3.56%)** |
| C vs C′ | 856 (3.36%) |
| A 현행 vs C″ (출생 진태양시, 절입 **KST** 時辰, 23=子 — 만세력 혼합 시계) | 1158 (4.55%) |
| C′ vs C″ | 719 (2.83%) |

이유: 두 끝점이 함께 ~28~40분 이동하면 어느 한쪽이 時辰 경계를 넘을 확률이 한쪽만 이동할 때의 약 두 배이고, 게다가 현행은 23시=亥
특례(lunar)인데 C′ 는 우리 자시 정책(23시=子)이라 23시대가 전부 한 時辰 어긋난다. Codex 구현(패킷 §3-1 그대로)의 격자 실측
2.8%(15,264건 중간값) 는 이 C′ 와 같은 계열이다. **따라서 패킷 §7 의 "변동 2% 초과 시 정지" 는 §2 예측 오차에서 나온 잘못된
정지선이다** — 구현 결함 신호가 아니다.

운영자 재결정 포인트(구현 검증 뒤 제시): 절입 끝점의 時辰을 (i) 출생과 같은 진태양시 시계로(C′, 논리 일관, ~3%) 둘지, (ii) 만세력
관행처럼 표준시(KST) 時辰으로 둘지(C″, 실측 4.55% — 변동이 더 크고 시계가 섞여 자리올림 일관성이 없다). 三命通會 예시는 만세력의
절입 時辰과 출생 時辰을 **같은 시계**로 전제하므로 (i)=C′ 가 문언에 가깝고 변동도 더 작다 → **C′ 유지 권장, 정지선만 상향**. 스크립트: `f1_axis_probe3.py`(부록 A 변형, zhejue 직접 구현).
