## 2. 구현
1. **`gen` 커맨드에 `--module` 반복 옵션 추가** (`integrated.py:726` 근방):
   `module: list[str] | None = typer.Option(None, "--module", help="질문 영역 모듈(반복): love|job|wealth|health|gunghap. 미지정=5모듈 전체")`.
   미지정(None)은 `build_integrated_full(modules=None)` = 5모듈 전체(하위호환, 승인 항목 ④).
2. **검증은 레지스트리에 위임**: CLI에서 모듈 목록을 자체 정규화·보정하지 않는다. 잘못된 값(미등록·중복·
   빈 목록)과 1인+gunghap은 `build_integrated_full` 내부 ValueError를 그대로 받아 **종료코드 1 + 원인
   메시지**로 끝낸다(조용한 보정·부분 진행 금지, PDF 미산출). 에러 메시지에 PII 없음(모듈 ID만).
3. **관측 출력**: 성공 시 기존 `PDF: ...` 라인에 더해 정규화된 선택 모듈을 한 줄 출력
   (예: `modules: love,job (schema v1)` — result["modules"] 사용, 자체 재계산 금지).
4. `render` 커맨드·조립·게이트·레지스트리는 무변경. content.json의 modules 준수는 1단계가 이미 보장한다.
