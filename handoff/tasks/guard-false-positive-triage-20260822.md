## 5. 범위에서 빼는 것

- **`settings.json` 의 `deny`(`Bash(rm:*)` 등) 는 오탐이 아니다.** 설계된 차단이고, 공식 문서상
  평가 순서가 `deny → ask → allow` 라 `allow` 로 못 이기며 **auto mode 로도 안 풀린다**
  (`code.claude.com/docs/en/permissions`). 파일 삭제는 운영자가 `! rm` 으로 한다.
  이 항목을 "오탐"으로 묶으면 진짜 원인이 흐려진다.
- **#2-a 자동승인(auto mode) 해제** — 별건이고 교차검토가 권고 철회를 요구해 수용했다.
  이 패킷에서 다루지 않는다.
- `PRIVATE_KEY_MATERIAL`(81행) 과 `APPROVAL_REQUIRED`(12-17행) 는 **무수정**.

1. **사건별 차단 코드 확정표.** 7건 각각에 대해 (도구명 / 실제 차단 코드 / 매치한 패턴 /

2. **재현 프로브.** `evaluateRequest` 가 export 되어 있으므로(79행) 합성 이벤트를 넣어

   (이 저장소에 임시 스크립트를 두지 않는다).
3. **양성 대조 필수.** 진짜 위험 케이스(실제 비밀 경로 접근·실제 파괴적 명령)가 **계속 차단되는지**
   같은 프로브로 확인한다. 완화 방향 제안이 나오면 그 제안이 양성 대조를 깨지 않음을 보여야 한다.
4. **제안은 하되 구현하지 않는다.** 1단계 산출물은 "원인 + 최소 수정 방향 + 그 수정이 깨지
   않는다는 근거"까지다. 실제 편집은 2단계.
