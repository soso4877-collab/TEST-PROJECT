# 설계 결정 논쟁 — 다층 검증 키트(vkit) 배포·이식 메커니즘

> Phase 5 프로토콜의 첫 실전 적용(dogfood). one-way door = 타 프로젝트에 배포되는 대외 계약.

## 1. 결정 주제와 기준
- 결정: vkit(L0~L4 검증 키트)을 타 프로젝트(1차 crypto-signal)에 어떻게 배포·이식하는가.
- one-way door 이유: 복수 채택처가 한 방식으로 채택하면 배포 메커니즘 변경 = 전 채택처 마이그레이션.
- 기준(우선순위): (1) 이식성 (2) 유지보수(전파 vs 드리프트) (3) 결합도 최소(하드게이트 결정론·무의존) (4) 자족성.
- SSOT: scripts/deadparam_scan.py, sajugen/render/verify.py(GATE_KEYS), docs/20, handoff/templates/design_debate.md.

## 2. 후보 안 + 트레이드오프
| 안 | 요지 | 장점 | 단점 | 롤백 비용 |
|---|---|---|---|---|
| A 복사-적응 | 정본 템플릿 복사 후 손 적응 | 무결합·무의존·결정론 | 드리프트, 복사 실수 | 최저 |
| B 공유 패키지 | pip 설치·import | 전파·DRY | 외부 의존→하드게이트 인질(ruff 거부 선례) | 최악(one-way door) |

## 3. 비평 라운드 (sg-design-critic — Opus, 신선 컨텍스트, 코드 대조)
critic 산출 요약(안별 치명 리스크, 전부 코드 실측 근거):
- **공통 전제 반증**: "도메인 무관 그대로 복사"가 코드와 불일치 — deadparam_scan.py `_EXCLUDE_SUBPATHS`
  sajugen 경로 리터럴, 기본 `paths=["sajugen","scripts"]`, test_gate_registry `>=20` 매직넘버,
  skeleton_lint_matrix 가 도메인 모듈 직접 import. **"도메인 무관"의 측정된 경계가 없다.**
- A: 사일런트 드리프트·부분 복사(게이트가 dead-param 됨=팬텀 메타 재현)·경로 미적응 오탐. 단
  결정론·무의존 불변엔 최적합(위반 위험 최저).
- B: 버전 스큐가 하드게이트 조용히 약화(ruff 거부 실패 재현), 공급망 표면, 회귀 전파 단일장애점.
  불변 위반 위험 **최고**.
- C: 생성기 자체가 미검증(잘못된 게이트 대량 배포), 스텁의 거짓 안심(no-op 대량 생산=fail-closed 위반).
- 치명 리스크 상위 3(안 무관): ① "이식됐지만 안 도는/스텁만" no-op 게이트=팬텀 메타 재현
  ② PII 탐지 도메인 형상 불일치(생년월일 vs 지갑·키·시크릿)→새 도메인 no-op 착시
  ③ 생성-비평 이질성이 채택 환경에 미배선(단일 모델이면 이질 렌즈가 자기토론으로 퇴화).
- 간과된 3안: **출처 스탬프 벤더링**(복사 + 상류 SHA 매니페스트 + 비차단 drift-check).

## 4. 저자 반박(≤1) + 판정
- 반박: B 는 "하드게이트 결정론·무의존"(기준 3·4) 정면 위반 + Phase 2 ruff 거부 선례의 재현이라
  기각(반박 불가 — critic 옳음). C 는 생성기가 게이트로 검증되지 않는 메타 사각 + 껍데기 게이트
  양산이라 기각. A 는 critic 도 불변 최적합으로 인정 — 유일 약점(드리프트·부분복사)은 critic 의
  간과된 3안(스탬프 벤더링 + drift-check + no-op 자가검증)으로 정확히 메워진다.
- **judge(루브릭, 기준 충족도)**: A+스탬프벤더링 0.85(불변 최적합·드리프트 완화) / B 0.25(불변 위반)
  / C 0.4(메타 사각). judge 추천 = **A + 스탬프 벤더링**.

## 5. 확정 (운영자 검토 대기)
- 채택안: **A(복사-적응) + 출처 스탬프 벤더링** — 정본 handoff/kit/ 복사, upstream SHA 매니페스트,
  비차단 drift-check. B/C 기각.
- critic 이 드러낸 4개 안전장치를 규격(docs/21)에 명문화(이식의 no-op·PII 착시 차단):
  1. **채택처 no-op 자가검증**: 게이트가 CI 에 실제 배선 + "결함 주입→차단" 양방 회귀가 존재하는지
     자가검증(없으면 "이식했으나 안 도는" 팬텀 메타 재현).
  2. **PII 형상 재정의 필수**: L2 PII 룰은 sajugen 형상(생년월일·이름) 고정이 아니라 도메인별 재정의
     (crypto = 지갑·키·시크릿). "탐지 존재=보호됨" 착시 금지.
  3. **이질성 채택 시 검증**: 생성 세션 실모델 ≠ 비평/judge 모델을 채택처에서 확인(단일 모델 퇴화 차단).
  4. **이식 전 도메인 리터럴 정리**: 복사 대상의 sajugen 경로·매직넘버(20키 floor 등)를 측정된
     경계표(docs/21)로 명시하고 채택 시 치환.
