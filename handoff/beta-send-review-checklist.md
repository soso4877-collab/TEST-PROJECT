# 베타 발송 전 검수 체크리스트 (현행: 2026-07-15)

> 운영자용 실행 체크리스트. SSOT 순서 = `docs/23-beta-operation.md` §2, 채우는 폼 = `handoff/templates/pdf_review_report.md`.
> 이 문서는 그 둘을 현재 상태(이번 세션 실측 focus)로 조작화한다. 중복 판정 시 docs/23·폼이 정본.
> **PII 0**: 이 체크리스트·보고서에 이름·생년월일·질문 원문·본문 전문을 넣지 않는다. 익명 ID(`DOC_A`)·메타만.

## 0. 순서 (고정 — 절대규칙 16: APPROVED 전 발송 물리 차단)

1. 표준 게이트 통과 (`gate_pass=True`) — 자동
2. hsweep 파일럿 계측 (Z 측정) — 3중 잠금 승인 시
3. 운영자 육안 검수 (아래 §2, `pdf_review_report.md` 폼 작성)
4. 전 항목 PASS + 운영자 전문 승인 → APPROVED 전이 → **수동 발송**

## 1. 자동 게이트 (전제 — 이게 False면 육안 이전에 반려)

- [ ] `summary.json`/verify `gate_pass=True`, 실패 게이트 키 0
- [ ] `selected_modules`가 주문 모듈과 일치, `minimum_pages` 적용 하한 정상(4모듈=28p/9000자)
- [ ] `delivery_failures` 없음 (질문축 누락·저밀도·보장 표현·외부 조언 0)
- [ ] 폴백 챕터 목록 확인 — 폴백 자체는 정상(가드 방어)이나 **폴백 챕터는 §2 문안 육안 필수**

## 2. 육안 검수 (300dpi PDF — `pdf_review_report.md` 폼에 PASS/FAIL 기록)

### 2-1. 금칙 텍스트 스캔 (전부 0이어야 — 발견 시 FAIL)
- [ ] **실명·생년월일·질문 원문** 0 (PII 유출)
- [ ] **예측 정확도 주장** 0: `적중`, `정확히 맞`, `100%`, `틀림없이/반드시/무조건/확실히/꼭`+결과동사, `보장`
- [ ] **AI/도구 산출 티** 0: `AI`, `자동 분석`, `프로그램`, `도구`, `생성`, `이 풀이는`류 자기지시 메타
- [ ] **서양 점성술 off-domain** 0: `별자리`, `황도`, `쌍둥이자리/게자리/사자자리…`(12궁명) — *이번 세션 closing에서 실 모델이 생성→가드 차단 관측. 폴백 후 잔재 재확인.*
- [ ] **삼주(생시 미상) 주문 한정 금칙** 0: `시주`, `時柱`, `사주팔자`, `자미두수`, `진태양시`, `정오`, 맨몸 월표기(`N월` 단독), 받침 뒤 조사 오류(`정축가`류)
- [ ] **문서 진행/섹션 예고 메타** 0: `다음 순서로`, `다음 장에서`, `~보겠습니다`(작업 예고), 빈 지시(`차례대로 확인하세요`)

### 2-2. 문안 품질 (폼 semantic_style_review + delivery_answer_review)
- [ ] **폴백 챕터 자연스러움**: 룰 폴백 챕터(예: love·flow·consult·closing)가 템플릿 티·반복·뭉툭함 없이 사람 상담 글로 읽힘
- [ ] **consult 직답**: 신청 질문에 consult 장이 직접 답함(1장 도입엔 직답 문단 없음 — 2026-07-05 개정)
- [ ] **명리↔자미 층위 통합**: 상충을 '모순' 아닌 층위 차이로 재서술, 명리 최종 권위
- [ ] 반복어·빈말·일반론(바넘) 과다 없음, 호명 자연스러움

### 2-3. 시각 조판 (visual_review_300dpi — 표지·consult·마지막 2쪽·표본 밀집쪽)
- [ ] **표지 h1** 음절 중간 개행 없음(어절 경계 개행·keep-all 확인)
- [ ] orphan/widow, 저밀도 페이지, 텍스트 잘림, 이미지↔텍스트 겹침, 낙관 겹침 없음
- [ ] 삼주 주문: 연·월·일 3열 원국표 + 고정 고지 1회, 시주/자미 미표시

### 2-4. 브랜드·PII 최종
- [ ] 브랜드 보이스·상품 등급 정합 (서담선생/사주도령 등)
- [ ] 이 검수 보고서 자체에 고객 PII 인용 0

## 3. hsweep 파일럿 (docs/23 §2-2, 감사 A-3)
- [ ] 후보 N → 생존 M → 확정 K, **운영자 신규 발견 Z 기록** (목표 **Z=0**, 정밀도 K/M ≥ 0.7)
- [ ] 3중 잠금 + 운영자 승인 후에만 실행. 결과는 docs/16 hsweep 절에 추기

## 4. 판정
- [ ] §1~§3 전 항목 PASS **AND** 운영자 전문 육안 승인 → `pdf_review_report.md` `release_allowed=true`
- [ ] 하나라도 FAIL → **발송 금지**, 원인별 처리: 게이트/문안 결함=수정 발주(Claude→Codex) / 조판=재렌더 / 폴백 문안=재생성 판단
- [ ] APPROVED 전이 후에만 수동 발송. 자동 발송 없음.

## 5. 현행 주의 (2026-07-15 실측)
- 4모듈 LLM-on 유료 확인 = **gate_pass=True·31p·회귀 0**(발급 가능). 단 compose 4챕(love·flow·consult·closing) 룰 폴백이 상시 발생 가능(실 Sonnet이 근거밖 간지·맨몸월·단정·서양 별자리 생성→가드 차단→폴백). **폴백 챕터 문안 육안이 이번 검수의 핵심.**
